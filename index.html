Observações

  1. O saldo devedor de cada título é o valor original deduzido dos pagamentos efetivamente lançados, conforme o item 2.

  3. Ao efetuar o pagamento, informe o nº do documento no comprovante para facilitar a conciliação. A baixa financeira é confirmada após a compensação.
  4. Os valores referem-se ao principal, sem acréscimo de encargos.
